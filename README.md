# This is my mma coaching web app for CSC 491, my Independent Project.

1. in root directory, run: venv/scripts/activate
2.  run: pip install -r requirements.txt

3. to run react server: npm run dev 
    - needs to be run from /frontend
    - run "cd frontend"

4. to run api server: uvicorn api.main:app --reload
    - run in root directory
